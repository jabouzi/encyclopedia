# Encyclopedia Islamiya — الموسوعة الإسلامية

A web application preserving and presenting content from the Islamic encyclopedia originally published at [islam.aljayyash.net/encyclopedia](https://web.archive.org/web/20100803053821/http://islam.aljayyash.net/encyclopedia).

## About

Encyclopedia Islamiya is a comprehensive Arabic-language Islamic reference covering 16 major topics in Islamic knowledge — from creed and worship to history, biography, and family life. The content is presented in a structured, readable format for Arabic-speaking audiences.

## Tech Stack

- **Framework**: Next.js 14.2 (React 18.3)
- **Database**: WatermelonDB — reactive, offline-capable client-side storage
- **Content**: Seeded from static data (`/data/encyclopedia.js`) structured as Books → Chapters → Articles
